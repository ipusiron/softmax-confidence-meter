# Softmax Confidence Meter 仕様書

## 1. 目的

スコア付き候補集合に温度付きsoftmaxを適用し、出力分布の形を可視化する教育用Webツールとする。製品名の「Confidence」は固有名であり、画面の評価値は「分布集中度」と呼ぶ。

本ツールは予測の正解確率、モデルの信頼性、校正状態、安全性を評価しない。

## 2. 実行環境

- HTML、CSS、JavaScriptだけの静的アプリケーション
- 外部依存関係なし
- GitHub Pagesおよび`file://`で動作
- 候補名・スコアを送信・保存しない
- 表示言語だけを`localStorage`へ保存できる。保存できない環境でも動作する

## 3. 入力

- 形式：1行に`候補名: スコア`、またはスコアだけ
- 候補数：2〜200件
- 入力長：20,000文字以下
- 候補名：100文字以下
- スコア：有限の10進数または指数表記
- 空行は無視する
- 不正な非空行はすべて行番号付きエラーとして報告する

`Infinity`、`-Infinity`、`NaN`、数値以外の接尾辞、複数のコロン、空の候補名、有限範囲を超える値は拒否する。

## 4. softmax

温度`T`は0より大きい有限値とし、画面では0.10〜5.00、初期値1.00とする。

```text
m = max(z)
p_i = exp((z_i - m) / T) / Σ_j exp((z_j - m) / T)
```

最大スコアを除算前に引き、指数関数のオーバーフローを抑える。出力値はすべて有限かつ0以上で、合計は浮動小数点誤差の範囲で1となる。

## 5. 分布指標

```text
H(p) = -Σ_i p_i log(p_i)
normalized_entropy = H(p) / log(n)
concentration = 1 - normalized_entropy
```

表示項目は次のとおり。

- 候補数
- 温度
- 最小〜最大スコア
- 首位の割合
- 首位と2位の割合差
- エントロピー（nats）
- 正規化エントロピー
- 分布集中度

固定の判定閾値や「高信頼」「判断困難」のような品質ラベルは付けない。

## 6. 候補表示

- 確率降順で表示する
- 同率の場合は入力順を維持する
- 先頭5件を常時表示する
- 6件以上では、省略件数と省略候補の確率合計を示す
- 展開操作で全件を確認できる

## 7. 日英対応

静的文言、ARIAラベル、プレースホルダー、サンプル、入力エラー、動的な指標と候補表示を日本語・英語で切り替える。言語切り替えによって数値結果は変えない。

## 8. セキュリティ

- ユーザー入力をHTMLとして解釈しない
- `innerHTML`、インラインイベントハンドラー、`eval`を使わない
- CSPで外部スクリプト、外部スタイル、外部通信、フレーム、オブジェクトを拒否する
- 入力件数・入力長・候補名長を制限する

## 9. 非目標

- 正解候補の決定
- 精度、校正誤差、Brier scoreの算出
- 分布外入力やモデル誤りの検出
- モデル性能・安全性・公平性の証明
- 機密情報を扱う保存・共有機能
