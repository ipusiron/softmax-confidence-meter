# Softmax Confidence Meter 仕様書

## 1. 目的

スコア付き候補集合に温度付きsoftmaxを適用し、出力分布の形を可視化する教育用Webツールとする。製品名の「Confidence」は固有名であり、画面の評価値は「分布集中度」と呼ぶ。

本ツールは予測の正解確率、モデルの信頼性、校正状態、安全性を評価しない。

## 2. 実行環境

- HTML、CSS、JavaScriptだけの静的アプリケーション
- 外部依存関係なし
- GitHub Pagesおよび`file://`で動作
- 候補名・スコアを送信・保存しない
- 表示言語だけを`localStorage`へ保存できる。保存できない環境でも動作する

## 3. 入力

- 形式：1行に`候補名: スコア`、またはスコアだけ
- 候補数：2〜200件
- 入力長：20,000文字以下
- 候補名：100文字以下
- スコア：有限の10進数または指数表記
- 空行は無視する
- 不正な非空行はすべて行番号付きエラーとして報告する

`Infinity`、`-Infinity`、`NaN`、数値以外の接尾辞、複数のコロン、空の候補名、有限範囲を超える値は拒否する。

## 4. softmax

温度`T`は0より大きい有限値とする。分布集中度メーターの画面範囲は0.10〜5.00、初期値1.00とする。2条件比較ラボでは数値入力を0.1〜10.0に制限する。

```text
m = max(z)
p_i = exp((z_i - m) / T) / Σ_j exp((z_j - m) / T)
```

最大スコアを除算前に引き、指数関数のオーバーフローを抑える。出力値はすべて有限かつ0以上で、合計は浮動小数点誤差の範囲で1となる。

## 5. 分布指標

```text
H(p) = -Σ_i p_i log(p_i)
normalized_entropy = H(p) / log(n)
concentration = 1 - normalized_entropy
```

表示項目は次のとおり。

- 候補数
- 温度
- 最小〜最大スコア
- 首位の割合
- 首位と2位の割合差
- エントロピー（nats）
- 正規化エントロピー
- 分布集中度

固定の判定閾値や「高信頼」「判断困難」のような品質ラベルは付けない。

## 6. 候補表示

- 確率降順で表示する
- 同率の場合は入力順を維持する
- 先頭5件を常時表示する
- 6件以上では、省略件数と省略候補の確率合計を示す
- 展開操作で全件を確認できる

## 7. 日英対応

静的文言、ARIAラベル、プレースホルダー、サンプル、入力エラー、動的な指標と候補表示を日本語・英語で切り替える。言語切り替えによって数値結果は変えない。

## 8. 2条件比較

条件Aと条件Bを、それぞれ独立した候補入力と温度で解析する。両条件には第3節と第4節の検証・計算規則を同じように適用する。

表示項目は次のとおり。

- 候補集合が同じか
- 候補順位が同じか。候補集合が異なる場合は直接比較不可とする
- 各条件の`(最大スコア - 最小スコア) / T`（実効スコア幅）
- 条件Bから条件Aを引いた集中度差と首位割合差
- 候補集合が同じ場合、同一候補における割合変化の最大絶対値
- 各条件の集中度、候補数、温度、スコア範囲、首位割合、上位候補

名前付き候補は入力順が異なっても同一候補として照合する。同点候補は入力順が違っても同じ順位グループとして扱う。名前を省略した候補は位置に基づく自動候補として扱う。同名候補が複数ある場合は、同名内の出現順で区別する。

次の4プリセットを提供する。

1. 同じスコアで温度だけを変更する
2. 温度を固定して全スコアを10倍にする
3. 全スコアと温度を同じ倍率にする
4. 既存スコアを保ったまま候補を追加する

候補集合が異なる比較は、同じ候補集合の前後差として解釈しない。比較結果は分布の変化だけを説明し、正解率、信頼性、品質、安全性の優劣を示さない。

## 9. セキュリティ

- ユーザー入力をHTMLとして解釈しない
- `innerHTML`、インラインイベントハンドラー、`eval`を使わない
- CSPで外部スクリプト、外部スタイル、外部通信、フレーム、オブジェクトを拒否する
- 入力件数・入力長・候補名長を制限する

## 10. 非目標

- 正解候補の決定
- 精度、校正誤差、Brier scoreの算出
- 分布外入力やモデル誤りの検出
- モデル性能・安全性・公平性の証明
- 機密情報を扱う保存・共有機能
